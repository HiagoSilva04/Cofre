# Cofre — Calculadora de Bits

Bem-vindo ao projeto Cofre!

## Sobre o projeto
O Cofre é uma ferramenta que calcula a quantidade de bits de informação de uma senha, utilizando o tamanho da senha e a quantidade de caracteres possíveis.

## Como funciona?
1. O usuário informa uma senha.
2. A ferramenta analisa os caracteres.
3. O sistema realiza o cálculo.
4. O resultado aparece na tela.

## Tecnologias utilizadas
- HTML
- CSS
- JavaScript
- Git
- GitHub

## Objetivo
O objetivo deste projeto é aprender programação, desenvolver uma ferramenta funcional e praticar o uso do Git e GitHub.

## Desenvolvedor
Projeto desenvolvido como atividade de Introdução à Ciência da Computação.
